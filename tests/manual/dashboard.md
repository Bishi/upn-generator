# Dashboard

> Dashboard monthly progress and next-step guidance

## Pre-conditions

- A billing month exists with no imported bills.
- A billing month with imported bills is available for comparison.

## Cases

- [ ] Select the empty month and confirm the dashboard shows a neutral "Import bills to begin" prompt with an Open bills action, without a validation error or red alert.
- [ ] Import a bill, return to the dashboard, and confirm validation errors appear only for actual bill, split, or delivery problems.
